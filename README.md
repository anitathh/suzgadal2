# Сузгадаль

Игра «угадай цену квартиры» по настоящим объявлениям Авито в Суздале и окрестностях.
Мобильная версия в приоритете: один экран — одна карточка.

**Как играть:** 10 квартир за раунд → листай фото в окошке со ставнями → двигай домик-бегунок → «Оценить» →
реальная цена, разница (переплата / недоплата), баллы и ссылка на объявление → в конце ты Крестьянин, Купец или Барин.

## Баллы

За каждую квартиру — до 1000 баллов, итого до 10 000. Считается по относительной ошибке `e = |назвал − реальная| / реальная`:

```
баллы = 1000 · exp(−3 · max(0, e − 0,02))
```

Ошибка до 2% — максимум; 10% → ≈ 787; 25% → ≈ 502; 50% → ≈ 237; 100% → ≈ 53.

## Кто ты в конце

Каждый ответ — «занизил» (ниже реальной больше чем на 10%), «в точку» (в пределах ±10%) или «завысил» (выше больше чем на 10%).
Чаще всего занижал — **Крестьянин**, чаще попадал — **Купец**, чаще завышал — **Барин**. Ничья — Купец.

## Запуск и публикация

Сайт полностью статический (HTML + CSS + JS, без сборки).

```bash
python3 -m http.server 8000   # открыть http://localhost:8000
```

GitHub Pages: *Settings → Pages → Deploy from a branch → `main` / `(root)`*. Файл `.nojekyll` уже лежит в корне.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка трёх экранов: старт, игра, итог |
| `style.css` | оформление, рамки, окно со ставнями, домик-бегунок, шрифты |
| `app.js` | логика: раунды, бегунок, баллы, шутки, итог |
| `data.js` | 64 объявления (цена за сутки, адрес, ссылка, фото) |
| `img/lots/` | фото квартир в WebP (≈ 6–8 КБ каждое) |
| `fonts/` | Ruslan Display, Kurale, Caveat (woff2, только кириллица/латиница) |

## Данные

Источник — таблица с объявлениями Авито. В игру попали объявления, у которых есть фото; дубликаты убраны.
Цены — **за сутки** (посуточная аренда). Фото в таблице — миниатюры 208×208 px, поэтому они сжаты в WebP без увеличения.
